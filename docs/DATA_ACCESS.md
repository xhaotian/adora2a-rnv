# Data access

All analyses use de-identified public data. Raw and processed data remain available from the original repositories.

The eight P17 OIR studies included in the meta-analysis are GSE130400, GSE194176, GSE234447, GSE241239, GSE259255, GSE289223, GSE301407, and GSE315511.

The primary human PDR rebuild uses donor-level endothelial pseudobulk data from GSE165784 and GSE245561. Contextual human analyses described in the article use GSE160306, GSE60436, GSE276892, GSE94019, GSE179568, GSE146887/GSE163090, and GSE234047, with their inferential limitations stated in the manuscript.

The article-associated `Source_Data.xlsx` contains the study-level inputs, the seven-donor model input, the blinded eligibility input, and the source values for the three main figures. It contains no direct identifiers. Place it in `inputs/` to use the documented commands.
